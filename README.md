# Shopping List

My first Flutter app: add items, mark them as bought, and delete them.

## Features
- Add an item with the text field and the Add button (or the Enter key)
- Tap an item to mark it as bought (crossed out), tap again to undo
- Delete an item with the bin icon
- Clear all bought items with the button in the top bar
- Refuses an empty item with the message "Type an item first"
